# 抓包指南：野狐棋谱 / 弈客直播 / 弈客棋谱

> 目的：拿到这些页面的**真实数据接口**（URL + 响应 JSON），以便在 LizzieYzy 中实现
> 「粘贴分享链接 → 自动加载棋谱/直播对局」。请按下面步骤抓包后把文件发给开发者。

---

## 0. 通用准备（Chrome / Edge 桌面版）

1. 打开浏览器，按 **F12** 打开开发者工具，切到 **Network（网络）** 面板；
2. 勾选：
   - **Preserve log（保留日志）**
   - **Disable cache（禁用缓存）**
3. 上方过滤栏选择 **Fetch/XHR**（若发现数据走 WebSocket，再切到 **WS** 面板）；
4. **先打开 F12 再刷新页面**，否则页面初始请求可能抓不到；
5. 复现操作（等棋谱/直播棋盘显示出来），在请求列表中找数据请求；
6. 交付方式（任选其一）：
   - 右键该请求 → **Copy → Copy as cURL (bash)**，粘贴到 txt 发我；
   - 或 Network 面板右上角 **↓ Export HAR**，把 .har 文件发我；
   - 或直接截图：请求 **URL + Headers + Response（JSON）**。
7. 隐私：Cookie/token 可打码，但请保留 **URL、请求方法、请求体、响应 JSON 结构**。

## 1. 野狐棋谱（h5 分享页）

**打开页面**（任选一个分享链接，示例）：
```
https://h5.foxwq.com/yehunewshare/?chessid=1792468463010001127&title=test&boardsize=19
```
也可以从野狐棋谱列表里点一个：`https://www.foxwq.com/qipu.html` → 「大赛棋谱」条目。

**抓什么**：
1. F12 → Network → Fetch/XHR → 刷新页面；
2. 在请求列表里搜 **chessid 数字**（如 `1792468463010001127`），或找响应里含
   `moves` / 落子坐标（如 `[["Q16",...]]`）/ `sgf` 的请求；
3. 记录：
   - 请求 **URL**（可能带 chessid / boardid / gameid 参数）
   - **请求方法**（GET/POST）与 Headers（重点是 `Referer`、`User-Agent`、任何 `x-*` 头）
   - **响应 JSON**（棋盘大小、落子序列、结果/贴目等字段）
4. 若数据来自 **WebSocket**：切 WS 面板 → 点连接 → **Messages**，复制帧内容（文本帧直接可见）。

我拿到后会：解析 chessid → 请求同一接口 → 转成 SGF 载入棋盘并自动分析。

## 2. 弈客直播

**打开页面**（示例）：
```
https://home.yikeweiqi.com/#/live/room/18328/1/15630642
```
（在弈客首页 `https://home.yikeweiqi.com/` → 直播 里点任意房间）

**抓什么**：
1. F12 → Network → Fetch/XHR → 刷新页面，等直播棋盘出现；
2. 找返回直播对局数据的请求，关键词：`golive`、`live`、`dtl`、`room`、`chess`、`moves`；
3. 记录 URL / 方法 / Headers / 响应 JSON；
4. 如果是**轮询**（每隔几秒重复请求）：记录轮询间隔与响应里"新增落子"的字段；
5. 如果走 **WebSocket**：记录握手 URL 与消息帧格式。

我拿到后会替换 `OnlineDialog` 里已失效的旧接口（`api.yikeweiqi.com/golive/dtl`），
复用现有的定时拉取 + 落子回放逻辑。

## 6. 附：弈客直播/大厅修复时，F12 具体看哪里

目标：找到"房间数据/落子数据"的请求（或 WebSocket 帧），以及"大厅房间列表"的接口。
旧代码用的是：`https://api.<域名>/golive/dtl?id=...`（已 500）和 socket.io
`https://rtgame.yikeweiqi.com`（事件 `login / entry_room / channel`，数据在 `game_info` 里，含 `sgf`）。

### 6.1 弈客直播（房间页）

1. 打开直播间页面（如 `https://home.yikeweiqi.com/#/live/room/18328/1/15630642`）；
2. **先按 F12** 打开 DevTools，切到 **Network**，勾选 **Preserve log**、**Disable cache**；
3. 过滤栏选 **Fetch/XHR**，然后刷新页面；
4. 在请求列表里找：
   - 域名含 `api.yikeweiqi.com` / `rtgame.yikeweiqi.com` 的请求；
   - URL 含 `golive`、`live`、`dtl`、`room`、`chess` 的请求；
   - 响应里含 `sgf`、`moves`、`game_info`、`blackName/whiteName`、`boardSize` 的 JSON；
5. **如果数据走 WebSocket**：切到 **WS** 面板 → 点 `rtgame.yikeweiqi.com` 的连接 →
   **Messages（消息）** 标签 → 在帧列表里找 `login`、`entry_room`、`channel`、`game_info`、`sgf` 字样；
   把这几帧内容复制下来（尤其 `game_info` 的 JSON）。
6. **找不到请求时**：在 **Sources** 面板按 **Ctrl+Shift+F** 全局搜索
   `golive`、`rtgame`、`entry_room`、`game_info`、`socket.io`，能定位到前端 JS 里的接口/事件名；
7. 也可以在 **Console** 里执行：
   ```js
   performance.getEntriesByType('resource').map(e => e.name).filter(n => n.includes('yikeweiqi'))
   ```
   直接列出页面加载过的弈客域名请求。

### 6.2 弈客大厅（房间列表）

1. 打开 `https://home.yikeweiqi.com/#/game`，F12 → Network → Fetch/XHR；
2. 刷新并等待大厅列表出现；
3. 找返回**房间列表**的 JSON（URL 含 `hall`、`room`、`list`、`golive`），
   记录：URL、请求参数、响应结构（房间 id、桌号、状态）；
4. 点进一个房间，重复 6.1 的步骤抓对局数据。

### 6.3 需要发给开发者的内容（最少）

| 项目 | 内容 |
|---|---|
| 房间页 | 房间数据请求 URL + 响应 JSON（或 WS 帧） |
| 大厅页 | 房间列表请求 URL + 响应 JSON |
| 共同 | 请求方法、必要 Headers（Cookie/Referer/UA 可打码）、房间 id 示例 |

如果 Network 里**只有 WS 连接、没有 XHR**，就导出 WS 帧；
如果两者都没有（页面报错、Console 有红字），把 Console 报错截图也发来——
这通常说明弈客服务端接口本身已下线（我们实测 `api.yikeweiqi.com` 返回 500）。
